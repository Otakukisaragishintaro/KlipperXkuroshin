# 中文测试清单

[返回中文 README](../README.zh-CN.md) | [中文安装指南](INSTALL.zh-CN.md)

> 本文是测试计划，不代表其中的测试已经执行或通过。请记录实际命令、完整输出、Klipper commit 和测试环境。

## 一、补丁与静态检查

- [ ] 检出 README 中指定的 Klipper 基准 commit。
- [ ] 执行 `git apply --check`，确认补丁可应用。
- [ ] 应用补丁，并执行 `git diff --check`。
- [ ] 对 `klippy/extras/bed_mesh.py` 执行 Python 语法编译检查。
- [ ] 运行上游 bed_mesh 相关回归测试。
- [ ] 确认默认重复次数为 1 时保留单次扫描行为。
- [ ] 确认重复次数 2 会被拒绝，3、4、5 可以通过配置验证。
- [ ] 确认结果数量不匹配时会给出清晰错误。
- [ ] 确认有效样本少于 2 个时会安全报错。
- [ ] 确认扫描、结果读取、过滤或最终回调抛出异常时，探针会话仍会结束。
- [ ] 确认 Klipper 在命令处理器退出后才分发 `gcode:command_error`，且 Eddy 不会在 `finally` 已清理会话后再次清理。
- [ ] 确认空 rapid-scan 路径会在启动探针会话前被拒绝。

## 二、行为回归检查

- [ ] 将单次扫描结果与未修改的 Klipper 进行比较。
- [ ] 确认每轮都重放完全相同的 rapid path，包括 overshoot 移动和探测点。
- [ ] 确认路径点顺序和结果数量一致。
- [ ] 确认 zero-reference 点和 faulty-region 替代点与其他路径点一样参与逐点过滤。
- [ ] 确认轴扭曲补偿通过现有 `probe:update_results` 事件，在 MAD 聚合前按原有顺序执行。
- [ ] 确认每个路径点只有一个聚合结果进入现有网床完成回调。
- [ ] 确认过滤器没有修改 Eddy 单个采样窗口的频率平均或频率到高度的标定。

## 三、可控异常值测试

使用合成数据或固定位置的受控测量，覆盖：

- [ ] 所有样本稳定、没有异常值。
- [ ] 一个明显偏高的异常值。
- [ ] 一个明显偏低的异常值。
- [ ] 奇数次和偶数次重复扫描。
- [ ] MAD 等于 0，由绝对阈值下限提供保护。
- [ ] 剩余有效样本少于 2 个时必须安全失败。
- [ ] 结果总数不等于 `rapid_scan_repeats * probe_point_count` 时必须安全失败。

## 四、测量噪声底评估

在热状态和机械状态稳定的条件下，对同一位置进行重复测量。根据实际噪声和测量分辨率评估绝对阈值。

**不要把 0.020 mm 当成已经验证的通用阈值。** 应记录设备、探针、温度、重复次数、原始读数和最终阈值选择依据。

## 五、向 Klipper 上游提交前

- [ ] 更新 Klipper 官方配置参考文档。
- [ ] 添加适当的自动化测试。
- [ ] 运行相关 Klipper 测试套件，并记录准确结果。
- [ ] 按 Klipper 贡献要求提供真实、准确的 Signed-off-by 身份信息。
- [ ] 完成代码审查和受控硬件验证后，再考虑向官方仓库提交 PR。
